# MindDock 使用文档

个人知识库 + 工作区驾驶舱的完整使用说明。启动后浏览器访问 <http://127.0.0.1:8765>。

## 1. 启动与停止

| 方式 | 操作 |
| --- | --- |
| 双击启动 | 项目根目录的 `run.bat` |
| 命令启动 | `python -m minddock`（默认命令即 serve） |
| 自定义 | `python -m minddock serve --port 9000 --data-dir D:\Notes --workspace D:\Workspace --no-browser` |
| 停止 | 命令行按 `Ctrl+C`，或直接关闭 bat 窗口 |

首次启动自动播种 26 篇演示笔记，方便直接体验全部功能；笔记库非空时绝不写入演示数据。

其他命令：

```bash
python -m minddock check     # 自检：配置、笔记数、工作区解析结果
python -m minddock seed      # 手动播种演示数据（仅当笔记库为空）
python -m minddock export    # 整库导出 → output/minddock-book.html（离线可看，无需开服务）
python -m minddock --version
```

端口被占用时自动顺延（8765 → 8766 → …，最多尝试 10 个），实际地址以启动日志为准。

## 2. 界面总览

顶部三个主视图（移动端在底部导航栏）：

- **笔记**：左侧笔记列表 + 右侧编辑器/预览
- **图谱**：全库双向链接关系图
- **驾驶舱**：工作区项目登记表 + 避坑日志可视化

顶栏常驻：全局搜索框（`Ctrl+K` 聚焦）、今日笔记 📅、新建 ＋、深浅主题切换 🌙/☀️。

## 3. 笔记

### 新建

- 顶栏 `＋` → 输入笔记名 → 确定
- **模板**：给任意笔记打上「模板」标签后，它会出现在新建对话框的「从模板开始」栏，点击选中（再点取消），新笔记自动复制其内容——比如演示库里的「周报模板」
- 笔记名即文件名，不允许 `\ / : * ? " < > |` 等字符与 Windows 保留名（con、nul 等）
- 每日笔记：点 📅 直接生成/打开当天 `YYYY-MM-DD` 笔记，自带「今日完成 / 明日计划 / 随记」模板

### 编辑

- 正文用 Markdown 书写，支持标题、列表、任务列表、表格、代码块、引用、粗斜体、删除线
- `[[笔记名]]` 建立双向链接，`[[笔记名|别名]]` 显示别名；输入 `[[` 即弹出**自动补全**（↑↓ 选择、回车确认）；链接不存在时显示为琥珀色虚线，预览里点击可快捷创建
- `#标签` 行内打标签，或用正文下方的标签栏管理（回车添加、× 删除）
- **自动保存**：停止输入约 0.9 秒后自动保存；`Ctrl+S` 立即保存；右上角显示保存状态
- **预览**：点「预览」分屏显示渲染效果（窄屏下为切换模式）
- **大纲**：编辑器底部「📋 大纲」列出正文所有标题行，点击直接跳到对应位置
- **重命名**：点「重命名」改笔记名，全库中指向它的 `[[双链]]` 文本会同步更新
- **版本历史**：每次保存自动把修改前内容留档（每篇保留最近 20 个版本）；点「历史」可查看任意版本内容并一键恢复（恢复前当前版本也会留档，不会丢失）
- **导出**：点「导出」把当前笔记下载为样式完整的单文件 HTML

### 快速跳转

`Ctrl+P` 打开命令面板，输入笔记名片段（匹配名称与标题），↑↓ 选择、回车直达。配合 `Ctrl+K`（搜索框聚焦）覆盖绝大多数导航场景。

### 图片

- 在编辑器里**直接粘贴截图**（Ctrl+V）或**拖入图片文件**，图片自动存入笔记库的 `attachments/` 目录并在光标处插入 `![](attachments/…)` 引用，随笔记自动保存
- 支持 PNG / JPG / GIF / WebP / BMP，单张上限 8MB
- 预览与导出（单篇 HTML、整库书册）都会内嵌图片，离线可看
- 删除笔记不会连带删除图片文件；`attachments/` 里未被任何笔记引用的图可手动清理

### 反向链接

编辑器底部「🔗 反向链接」列出所有链接到当前笔记的笔记，点击即跳转。

### 搜索

- 顶栏搜索框即搜即显，多关键词用空格分隔（AND 语义）
- 中文按子串匹配，英文按整词匹配（搜 `pyth` 不会命中 `python`）；标题命中权重高于正文
- 结果按相关度排序，列表中高亮命中词；`Esc` 清空搜索

### 标签筛选

列表上方的标签胶囊（取前 24 个热标签，附计数）点击即筛选，再点「全部」清除。可与其他筛选叠加。

**重命名/合并标签**：点选一个标签后，再点标签栏末尾的 ✎，输入新名即可全库同步（含行内 `#标签`）；目标名已存在时自动合并。

### 删除与回收站

- 「删除」把笔记移入回收站（数据目录下 `.trash/`），不直接丢失
- 列表面板右上 🗑 进入回收站：可「↩ 恢复」或「✕ 彻底删除」
- 原名被占用时恢复为「xxx (恢复)」

## 4. 图谱

- 节点 = 笔记（大小按链接数），连线 = `[[双链]]`；未解析的链接目标显示为虚线幽灵节点
- 颜色按笔记的第一个标签着色，右上角图例可点击高亮同标签节点
- 拖拽节点、滚轮缩放（0.3×–3×）、拖空白处平移
- 点击普通节点打开笔记；点击幽灵节点弹出新建对话框（预填名称）

## 5. 驾驶舱

聚合工作区两个文件，**只读**，绝不写入工作区：

| 数据 | 来源 | 展示 |
| --- | --- | --- |
| 项目登记表 | `projects/README.md` 的表格行 | 项目卡片表格 + 状态徽章（已完成/进行中/其他）+ 状态分布环图 |
| 避坑日志 | `docs/pitfall-log.md` | 「当前有效教训」编号卡片 + 按日期归档的折叠记录 |

另有笔记侧统计：总数、字数、标签数、回收站、近 30 天活跃度柱状图、标签分布条形图。

- 驾驶舱右上「⬇ 整库导出」：把整个笔记库下载为**单文件离线 HTML**（含目录、全文搜索、双链跳转、标签过滤），可直接发给别人或放手机看
- 工作区根目录不可用时自动回退到内置演示夹具，页面显示「演示数据」徽章

## 6. 配置

配置优先级：**命令行参数 > 项目根 `config.json` > 内置默认**。

`config.json` 示例（键不在支持列表内会被忽略，文件损坏时安全回退默认值）：

```json
{
  "host": "127.0.0.1",
  "port": 8765,
  "data_dir": "D:/Notes",
  "workspace_root": "E:/CodexWork",
  "open_browser": true
}
```

- `data_dir`：笔记库目录（相对路径按项目根解析）。指向任意真实 Markdown 目录即可把 MindDock 当日常笔记工具用，外部改动（含同步盘）会被自动感知
- `workspace_root`：驾驶舱数据来源，只读
- 局域网访问：`--host 0.0.0.0` 启动（注意服务无鉴权，仅建议在可信网络使用）

## 7. 数据与文件格式

- 一篇笔记 = 一个 `笔记名.md` 文件，头部 frontmatter 记录 `title / tags / created / updated`
- 粘贴带 frontmatter 的文本会被自动吸收合并
- 文件一律 UTF-8 写入；读取外部文件时 UTF-8 失败自动回退 GBK
- 回收站：`<data_dir>/.trash/`（内容 + `index.json` 索引）

## 8. 常见问题

**Q：换了笔记目录后数据还在吗？** 笔记就是普通 `.md` 文件，换目录只改配置，文件随目录走。

**Q：同步盘/外部编辑器改动会冲突吗？** 服务按文件 mtime 签名感知外部修改并自动重建缓存，无需重启。

**Q：演示数据能删吗？** 可以，直接在应用里逐篇删除，或清空 `data/notes/` 后重启（会重新播种，因为目录为空；不想再看到演示内容就保留至少一篇自己的笔记）。

**Q：忘记关服务占着端口？** 端口被占时下次启动自动顺延，无冲突风险。

**Q：笔记多了会卡吗？** 千篇规模实测：搜索/列表/图谱均在 0.1 秒级，单篇打开毫秒级。批量从外部导入上千个文件时，首次打开每个文件有杀毒软件扫描开销，之后走缓存不再重复。

**Q：如何完全回滚本项目的所有改动？** 项目全部文件只在 `minddock/` 文件夹内，对项目外零写入；删除该文件夹即恢复原状。
